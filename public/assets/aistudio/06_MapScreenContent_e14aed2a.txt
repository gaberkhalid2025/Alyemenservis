## التعديل 3: أيقونة الملاحة في لوحة التحكم (`onToggleNavigation` قرب السطر 478)
```kotlin
onToggleNavigation = {
    when {
        !hasRealLocation -> {
            viewModel.startLocationUpdates()
            coroutineScope.launch { snackbarHostState.showSnackbar("فعّل GPS وانتظر تحديد موقعك ثم أعد المحاولة") }
        }
        !state.startNavigation(state.selectedEntity) -> {
            coroutineScope.launch { snackbarHostState.showSnackbar("اختر وجهة أولاً: اضغط على مكان في الخريطة أو ابحث عنه") }
        }
    }
},
```

## التعديل 9 (مهم): لا تنقل «موقع المستخدم» عند اختيار مدينة
في `MapFilterBar(...)` داخل `onCitySelected` و`onSearchExecute` يوجد استدعاء `viewModel.updateUserLocation(coords.latitude, coords.longitude)`:
هذا يجعل **مركز المدينة هو موقعك** فتنطلق الملاحة من نقطة وهمية، وتصبح `hasRealLocation = true` خطأً.
- **احذف** هذين الاستدعاءين. الخريطة تتمركز على المدينة أصلاً عبر `selectedCity` (`window.setCity` في RealLeafletMapView).
- `onCitySelected = { city -> state.selectedCity = city }`
