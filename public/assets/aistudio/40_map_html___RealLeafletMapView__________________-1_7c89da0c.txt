## ما تأكدت من تطبيقه (سليم)
دائرة الدقة تتحدّث، `esc` وعقد العلامات، دوال المسار والمحطات ودبوس البحث، `dragstart`، التمركز الأولي مرة واحدة، عدم القفز لصنعاء عند «الكل»، `allowFileAccess=false`، وعدم تفعيل تصحيح WebView.

## المشاكل
### 1) الإسناد (Attribution) غير كافٍ ومخفي (عالية: ترخيص)
- نصوص الإسناد في الطبقات: `'OSM'` و`'HOT'` و`'Topo'` و`'Esri'` فقط. رخصة OSM (ODbL) تشترط عبارة «© مساهمو OpenStreetMap» ظاهرة مع رابط لصفحة الحقوق؛ OpenTopoMap (CC-BY-SA) تشترط ذكر OSM وSRTM والنمط؛ وEsri تشترط نص مصدر الصور.
- CSS يجعل الخط **7.5px** بلون رمادي على أسود، و`pointer-events: none` فلا يمكن فتح أي رابط.
- شريط الوضع يكتب «الأقمار الاصطناعية (OAM)» بينما المصدر Esri (وصف خاطئ للمصدر).
- «Vela 3D (مباني ثلاثية الأبعاد)» ما زال في `setLayer` (المستند 33).
### 2) الخادم
- `https://{s}.tile.openstreetmap.org` بالنطاقات a/b/c: سياسة OSM الحالية توصي بالنطاق الواحد `tile.openstreetmap.org`. وتعبير المعترض (`[a-c]\.`) سيفشل إن تغيّر العنوان.
- Esri World Imagery: الاستخدام في تطبيق إنتاجي يخضع لشروط Esri وقد يتطلب مفتاح ArcGIS؛ راجعها قبل النشر.
### 3) لا إشعار عند فشل البلاطات
بلا إنترنت وبلا كاش تظهر خريطة سوداء بلا تفسير (الصفحة المحلية تُحمَّل، فلا يظهر أي خطأ).
### 4) لا إيقاف للـ WebView عند خلفية التطبيق
لا `onPause()/onResume()`: يبقى JavaScript والمؤقتات (والبلاطات) تعمل والتطبيق في الخلفية ⇒ استهلاك بطارية.
### 5) `object MapAssetMemoryCache` مزيّف (يعيد `true`/`""`) — احذفه مع `MapTestRunner`.

```javascript
var tileOk = 0, tileErr = 0, tilesFailingNotified = false;
function notifyTiles(failing) {
    if (window.AndroidBridge && window.AndroidBridge.onTilesFailing) window.AndroidBridge.onTilesFailing(failing);
}
function watchLayer(layer) {
    tileOk = 0; tileErr = 0; tilesFailingNotified = false;
    layer.off('tileload'); layer.off('tileerror');
    layer.on('tileload', function () {
        tileOk++;
        if (tilesFailingNotified && tileOk >= 4) { tilesFailingNotified = false; notifyTiles(false); }
    });
    layer.on('tileerror', function () {
        tileErr++;
        if (!tilesFailingNotified && tileErr >= 6 && tileOk < tileErr / 4) { tilesFailingNotified = true; notifyTiles(true); }
    });
}
```

## ج) RealLeafletMapView.kt

2. فتح روابط الإسناد خارجياً بقائمة بيضاء (داخل `shouldOverrideUrlLoading` بالنسختين):
```kotlin
private val ALLOWED_HOSTS = setOf("www.openstreetmap.org", "www.hotosm.org", "opentopomap.org", "www.esri.com")
...
override fun shouldOverrideUrlLoading(view: WebView?, request: WebResourceRequest?): Boolean {
    val uri = request?.url ?: return true
    if (uri.scheme == "file") return false                         // الصفحة المحلية فقط
    if (uri.scheme == "https" && uri.host in ALLOWED_HOSTS) {
        try { context.startActivity(Intent(Intent.ACTION_VIEW, uri).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)) } catch (_: Exception) {}
    }
    return true                                                   // لا يُحمَّل أي رابط آخر داخل الخريطة
}
```
(وبالمثل للنسخة ذات `url: String?`.)
3. إيقاف/استئناف حسب دورة الحياة:
```kotlin
val lifecycleOwner = androidx.lifecycle.compose.LocalLifecycleOwner.current   // أو androidx.compose.ui.platform.LocalLifecycleOwner حسب إصدارك
DisposableEffect(lifecycleOwner, webViewRef) {
    val observer = androidx.lifecycle.LifecycleEventObserver { _, event ->
        when (event) {
            androidx.lifecycle.Lifecycle.Event.ON_PAUSE -> webViewRef?.onPause()
            androidx.lifecycle.Lifecycle.Event.ON_RESUME -> webViewRef?.onResume()
            else -> {}
        }
    }
    lifecycleOwner.lifecycle.addObserver(observer)
    onDispose { lifecycleOwner.lifecycle.removeObserver(observer) }
}
```
