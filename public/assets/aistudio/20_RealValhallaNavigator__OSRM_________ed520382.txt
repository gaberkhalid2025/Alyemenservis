# 20 – RealValhallaNavigator.kt + OnlineOsrmNavigator.kt + ملفات التهيئة (المتبقي)
**الإجراء:** تعديلات موضعية.

## أ) RealValhallaNavigator.kt
### 1) إبقاء محرك Valhalla واحداً بدل إنشائه وإغلاقه في كل طلب
حالياً يُنشأ `Valhalla(configPath)` ويُغلق مع كل مسار (تحميل ملف خرائط كامل كل مرة = بطء).
```kotlin
private var cachedEngine: com.valhalla.valhalla.Valhalla? = null
private var cachedConfigPath: String? = null

/** تُستدعى فقط داخل nativeMutex. */
private fun engineFor(configPath: String): com.valhalla.valhalla.Valhalla {
    val existing = cachedEngine
    if (existing != null && cachedConfigPath == configPath) return existing
    try { existing?.close() } catch (_: Throwable) {}
    return com.valhalla.valhalla.Valhalla(configPath).also { cachedEngine = it; cachedConfigPath = configPath }
}

/** يجب استدعاؤها قبل استبدال ملفات الخرائط (من المنزِّل) وعند أي خطأ أصلي. */
suspend fun releaseEngine() = nativeMutex.withLock {
    try { cachedEngine?.close() } catch (_: Throwable) {}
    cachedEngine = null; cachedConfigPath = null
}
```
وفي `tryRouteWithNativeValhalla` استبدل كتلة الإنشاء بـ:
```kotlin
val responseJson = try {
    engineFor(configFile.absolutePath).routeRaw(requestJson)
} catch (t: Throwable) {
    try { cachedEngine?.close() } catch (_: Throwable) {}   // فشل أصلي: تخلّص من المحرك ليُعاد إنشاؤه
    cachedEngine = null; cachedConfigPath = null
    throw t
}
```
واحذف فرع الـ Reflection المكرر (نفس الصنف تماماً؛ لا فائدة منه وقد يضاعف زمن الفشل).
> اطلب من المنزِّل استدعاء `RealValhallaNavigator.releaseEngine()` أول `installFromZip` قبل تبديل المجلد.

### 2) `ManeuverType.MERGE`
تحقق في ملف النماذج: إن لم تكن القيمة `MERGE` موجودة في `enum ManeuverType` فاستبدلها في `mapValhallaManeuver` بـ `ManeuverType.HIGHWAY_ENTER` (المستخدمة في OSRM).

### 3) تعليمات للدخول إلى الدوّار
Valhalla يعطي `roundabout_exit_count`؛ مرّره إن كان `ArabicInstructionFormatter.format` يدعم رقم المخرج (أضف معاملاً اختيارياً `roundaboutExit: Int? = null` دون كسر الاستدعاءات القديمة) لتنطق: «ادخل الدوّار واخرج من المخرج الثالث».

## ب) OnlineOsrmNavigator.kt
### 1) استبدل `mapManeuver` (تغطية «end of road» و«fork» وتحويلات الدوّار):
```kotlin
private fun mapManeuver(type: String, modifier: String): ManeuverType {
    fun byModifier(): ManeuverType = when (modifier) {
        "left" -> ManeuverType.LEFT
        "right" -> ManeuverType.RIGHT
        "sharp left" -> ManeuverType.SHARP_LEFT
        "sharp right" -> ManeuverType.SHARP_RIGHT
        "slight left" -> ManeuverType.SLIGHT_LEFT
        "slight right" -> ManeuverType.SLIGHT_RIGHT
        "uturn" -> ManeuverType.UTURN
        else -> ManeuverType.STRAIGHT
    }
    return when (type) {
        "depart" -> ManeuverType.START
        "arrive" -> ManeuverType.DESTINATION
        "turn", "end of road", "fork", "continue" -> byModifier()
        "new name" -> ManeuverType.STRAIGHT
        "roundabout", "rotary", "roundabout turn", "exit roundabout", "exit rotary" -> ManeuverType.ROUNDABOUT
        "on ramp", "merge" -> ManeuverType.HIGHWAY_ENTER
        "off ramp" -> ManeuverType.HIGHWAY_EXIT
        else -> byModifier()
    }
}
```

### 3) الخادم
- `NavConfig.OSRM_BASE_URL` يجب أن يكون **HTTPS**، وإلا يمنعه النظام (`usesCleartextTraffic=false`) وتفشل كل الطلبات بصمت.
- خادم `router.project-osrm.org` العام للتجارب فقط (يحد الطلبات وبلا ضمان). للإنتاج: خادم OSRM/Valhalla خاص بك أو مزود مدفوع.
- أضف `&alternatives=false` للرابط لتقليل حجم الرد.
