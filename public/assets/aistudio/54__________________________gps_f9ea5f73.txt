# 54 – ميزة «العنوان بالمعلم»: حل عملي لتشويش GPS في اليمن
**الفكرة (من وثيقتك):** المستخدم لا يعتمد على إشارة GPS؛ يختار معلماً معروفاً (مسجد/مدرسة/محل/سوق) ثم يضغط على الخريطة ليحدد موقع منزله، فيحسب التطبيق الإزاحة ويحفظ **«عنواناً مرئياً»**: «على بعد 80 م شمال مسجد النور، البوابة الحمراء». يراه السائق/الفني ويملك نقطتين على الخريطة (المعلم + الموقع).
**القيود:** بلا مفاتيح API ولا خدمات مدفوعة. الاعتماد على: خريطة OSM الموجودة، بحث Nominatim (موجود)، وOverpass API العام (اختياري، مجاني بلا مفتاح) لاقتراح المعالم القريبة.
**مبدأ الأمان من الأخطاء:** كل التعديلات على الملفات الموجودة **إضافات بقيم افتراضية** (معاملات اختيارية)، والباقي ملفات جديدة. لا يتغير سلوك أي شاشة حالية إن لم تُستعمل الميزة.

## 1) ملف جديد: `LandmarkAddress.kt`
```kotlin
package com.example.utils

import org.json.JSONObject
import java.util.Locale
import java.util.UUID
import kotlin.math.atan2
import kotlin.math.cos
import kotlin.math.roundToInt
import kotlin.math.sqrt

/**
 * عنوان مرئي: معلم مرجعي + نقطة المستخدم + وصف نصي.
 * لا يعتمد على GPS؛ النقطة يحددها المستخدم على الخريطة، والإزاحة تُحسب منها.
 */
data class LandmarkAddress(
    val id: String = UUID.randomUUID().toString(),
    val label: String,                 // «منزلي»، «عملي»
    val landmarkName: String,          // «مسجد النور»
    val landmarkLat: Double,
    val landmarkLng: Double,
    val pointLat: Double,              // موقع المنزل كما حدده المستخدم
    val pointLng: Double,
    val description: String,           // «البوابة الحمراء» (إلزامي)
    val createdAt: Long = System.currentTimeMillis()
) {
    val northMeters: Double get() = (pointLat - landmarkLat) * METERS_PER_DEG
    val eastMeters: Double get() = (pointLng - landmarkLng) * METERS_PER_DEG * cos(Math.toRadians(landmarkLat))
    val distanceMeters: Double get() = sqrt(northMeters * northMeters + eastMeters * eastMeters)

    /** أحد الاتجاهات الثمانية بالعربية (من المعلم إلى النقطة). */
    fun directionArabic(): String {
        val bearing = (Math.toDegrees(atan2(eastMeters, northMeters)) + 360.0) % 360.0
        return DIRECTIONS[(((bearing + 22.5) / 45.0).toInt()) % 8]
    }

    /** «على بعد 80 م شمال مسجد النور، البوابة الحمراء» */
    fun describe(): String {
        val d = distanceMeters
        val where = if (d < 15.0) "عند $landmarkName" else "على بعد ${roundMeters(d)} ${directionArabic()} $landmarkName"
        val desc = description.trim()
        return if (desc.isEmpty()) where else "$where، $desc"
    }

    /** null = صالح، وإلا رسالة الخطأ بالعربية. */
    fun validate(): String? = when {
        label.isBlank() -> "اسم العنوان مطلوب"
        landmarkName.isBlank() -> "اسم المعلم مطلوب"
        !isValid(landmarkLat, landmarkLng) -> "موقع المعلم غير صالح"
        !isValid(pointLat, pointLng) -> "موقع النقطة غير صالح"
        description.trim().length < 3 -> "الوصف النصي مطلوب (مثل: البوابة الحمراء، الدور الثاني)"
        distanceMeters > MAX_OFFSET_METERS -> "النقطة بعيدة عن المعلم أكثر من ${MAX_OFFSET_METERS.toInt()} م؛ اختر معلماً أقرب"
        else -> null
    }

    fun toJson(): JSONObject = JSONObject()
        .put("id", id).put("label", label).put("landmarkName", landmarkName)
        .put("landmarkLat", landmarkLat).put("landmarkLng", landmarkLng)
        .put("pointLat", pointLat).put("pointLng", pointLng)
        .put("description", description).put("createdAt", createdAt)

    /** للإرسال مع الحجز (Firestore): يحمل الإحداثيات والوصف الجاهز للعرض. */
    fun toMap(): Map<String, Any> = mapOf(
        "id" to id, "label" to label, "landmarkName" to landmarkName,
        "landmarkLat" to landmarkLat, "landmarkLng" to landmarkLng,
        "pointLat" to pointLat, "pointLng" to pointLng,
        "description" to description.trim(),
        "northM" to northMeters.roundToInt(), "eastM" to eastMeters.roundToInt(),
        "text" to describe(), "createdAt" to createdAt
    )

    companion object {
        const val METERS_PER_DEG = 111_195.0
        const val MAX_OFFSET_METERS = 1500.0
        private val DIRECTIONS = listOf("شمال", "شمال شرق", "شرق", "جنوب شرق", "جنوب", "جنوب غرب", "غرب", "شمال غرب")

        fun isValid(lat: Double, lng: Double) =
            !lat.isNaN() && !lng.isNaN() && lat in -90.0..90.0 && lng in -180.0..180.0 && !(lat == 0.0 && lng == 0.0)

        fun roundMeters(d: Double): String = when {
            d < 100.0 -> "${((d / 5.0).roundToInt() * 5).coerceAtLeast(5)} م"
            d < 1000.0 -> "${(d / 10.0).roundToInt() * 10} م"
            else -> String.format(Locale.US, "%.1f", d / 1000.0).removeSuffix(".0") + " كم"
        }

        fun fromJson(o: JSONObject): LandmarkAddress? = try {
            LandmarkAddress(
                id = o.optString("id").ifBlank { UUID.randomUUID().toString() },
                label = o.getString("label"), landmarkName = o.getString("landmarkName"),
                landmarkLat = o.getDouble("landmarkLat"), landmarkLng = o.getDouble("landmarkLng"),
                pointLat = o.getDouble("pointLat"), pointLng = o.getDouble("pointLng"),
                description = o.optString("description"), createdAt = o.optLong("createdAt", System.currentTimeMillis())
            )
        } catch (e: Exception) { null }

        /** قراءة عنوان وصل من Firestore (حقل landmarkAddress في الحجز). */
        fun fromMap(m: Map<String, Any?>): LandmarkAddress? {
            fun d(k: String) = (m[k] as? Number)?.toDouble()
            return try {
                LandmarkAddress(
                    id = (m["id"] as? String) ?: UUID.randomUUID().toString(),
                    label = (m["label"] as? String) ?: "العنوان",
                    landmarkName = m["landmarkName"] as? String ?: return null,
                    landmarkLat = d("landmarkLat") ?: return null, landmarkLng = d("landmarkLng") ?: return null,
                    pointLat = d("pointLat") ?: return null, pointLng = d("pointLng") ?: return null,
                    description = (m["description"] as? String).orEmpty(),
                    createdAt = (m["createdAt"] as? Number)?.toLong() ?: System.currentTimeMillis()
                )
            } catch (e: Exception) { null }
        }
    }
}
```
## 2) ملف جديد: `LandmarkAddressStore.kt` (تخزين مشفّر على الجهاز)
عنوان المنزل بيانات حساسة؛ يُحفظ مشفّراً (المكتبة `security-crypto` موجودة في مشروعك). **لا يُرسل لأي خادم إلا عند إرفاقه بحجز.**
```kotlin
package com.example.utils

import android.content.Context
import android.content.SharedPreferences
import android.util.Log
import androidx.security.crypto.EncryptedSharedPreferences
import androidx.security.crypto.MasterKey
import org.json.JSONArray

class LandmarkAddressStore(context: Context) {

    private val prefs: SharedPreferences? = try {
        EncryptedSharedPreferences.create(
            context, "landmark_addresses",
            MasterKey.Builder(context).setKeyScheme(MasterKey.KeyScheme.AES256_GCM).build(),
            EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV,
            EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM
        )
    } catch (e: Exception) {
        Log.e(TAG, "Encrypted prefs unavailable: ${e.message}")
        null                                   // لا نخزن بيانات حساسة نصاً صريحاً عند فشل التشفير
    }

    @Synchronized fun getAll(): List<LandmarkAddress> {
        val raw = prefs?.getString(KEY, null) ?: return emptyList()
        return try {
            val arr = JSONArray(raw)
            (0 until arr.length()).mapNotNull { LandmarkAddress.fromJson(arr.getJSONObject(it)) }
        } catch (e: Exception) { emptyList() }
    }

    /** true عند نجاح الحفظ (والعنوان صالح). */
    @Synchronized fun save(address: LandmarkAddress): Boolean {
        val p = prefs ?: return false
        if (address.validate() != null) return false
        val list = (listOf(address) + getAll().filterNot { it.id == address.id }).take(MAX_ADDRESSES)
        val arr = JSONArray().also { a -> list.forEach { a.put(it.toJson()) } }
        return p.edit().putString(KEY, arr.toString()).commit()
    }

    @Synchronized fun delete(id: String): Boolean {
        val p = prefs ?: return false
        val arr = JSONArray().also { a -> getAll().filterNot { it.id == id }.forEach { a.put(it.toJson()) } }
        return p.edit().putString(KEY, arr.toString()).commit()
    }

    companion object { private const val TAG = "LandmarkStore"; private const val KEY = "addresses_json"; const val MAX_ADDRESSES = 10 }
}
```
> إنشاء `EncryptedSharedPreferences` قد يستغرق عشرات الملّي ثانية؛ أنشئ الـ Store مرة واحدة (`remember`) واقرأ/اكتب داخل `Dispatchers.IO` كما في الشاشة أدناه.

## 3) ملف جديد: `LandmarkFinder.kt` (اقتراح معالم قريبة، مجاني بلا مفتاح)
يستعلم **Overpass API العام** عن المساجد والمدارس والأسواق والمستشفيات والصيدليات والبنوك ذات الاسم حول نقطة. استعمال عادل: كاش 5 دقائق وطلب واحد في كل مرة؛ وإن فشل (لا إنترنت/ازدحام) يرجع المستخدم للبحث أو للنقر اليدوي على الخريطة.
```kotlin
package com.example.utils

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext
import org.json.JSONObject
import java.net.HttpURLConnection
import java.net.URL
import java.net.URLEncoder
import java.util.Locale
import java.util.concurrent.ConcurrentHashMap

data class LandmarkCandidate(val name: String, val lat: Double, val lng: Double, val kind: String, val distanceM: Double)

object LandmarkFinder {
    @Volatile var lastError: String? = null
    private val cache = ConcurrentHashMap<String, Pair<Long, List<LandmarkCandidate>>>()
    private val mutex = Mutex()
    private const val ENDPOINT = "https://overpass-api.de/api/interpreter"     // يمكن تغييره لخادم Overpass آخر مجاني

    suspend fun nearby(lat: Double, lng: Double, radiusM: Int = 1200): List<LandmarkCandidate> = withContext(Dispatchers.IO) {
        lastError = null
        if (!LandmarkAddress.isValid(lat, lng)) return@withContext emptyList()
        val key = String.format(Locale.US, "%.3f_%.3f_%d", lat, lng, radiusM)
        cache[key]?.let { (t, v) -> if (System.currentTimeMillis() - t < 5 * 60_000L) return@withContext v }

        mutex.withLock {
            var c: HttpURLConnection? = null
            try {
                val la = String.format(Locale.US, "%.6f", lat)
                val lo = String.format(Locale.US, "%.6f", lng)
                val q = "[out:json][timeout:15];nwr(around:$radiusM,$la,$lo)[\"amenity\"~\"^(place_of_worship|school|marketplace|hospital|pharmacy|bank)\$\"][\"name\"];out center 40;"
                c = (URL(ENDPOINT).openConnection() as HttpURLConnection).apply {
                    requestMethod = "POST"; doOutput = true
                    connectTimeout = 10_000; readTimeout = 20_000
                    setRequestProperty("User-Agent", "AlYemenServicesApp/1.0")
                    setRequestProperty("Content-Type", "application/x-www-form-urlencoded; charset=UTF-8")
                }
                c.outputStream.use { it.write(("data=" + URLEncoder.encode(q, "UTF-8")).toByteArray(Charsets.UTF_8)) }
                when (val code = c.responseCode) {
                    200 -> {
                        val root = JSONObject(c.inputStream.bufferedReader().use { it.readText() })
                        val els = root.optJSONArray("elements")
                        val out = mutableListOf<LandmarkCandidate>()
                        if (els != null) for (i in 0 until els.length()) {
                            val e = els.getJSONObject(i)
                            val tags = e.optJSONObject("tags") ?: continue
                            val name = tags.optString("name:ar").ifBlank { tags.optString("name") }
                            if (name.isBlank()) continue
                            val center = e.optJSONObject("center")
                            val la2 = if (e.has("lat")) e.optDouble("lat") else center?.optDouble("lat") ?: Double.NaN
                            val lo2 = if (e.has("lon")) e.optDouble("lon") else center?.optDouble("lon") ?: Double.NaN
                            if (!LandmarkAddress.isValid(la2, lo2)) continue
                            val kind = when (tags.optString("amenity")) {
                                "place_of_worship" -> if (tags.optString("religion") == "muslim" || tags.optString("religion").isBlank()) "مسجد" else "دار عبادة"
                                "school" -> "مدرسة"; "marketplace" -> "سوق"; "hospital" -> "مستشفى"
                                "pharmacy" -> "صيدلية"; "bank" -> "بنك"; else -> "معلم"
                            }
                            out.add(LandmarkCandidate(name, la2, lo2, kind, HaversinePrecisionNavigator.calculateDistance(lat, lng, la2, lo2)))
                        }
                        val result = out.distinctBy { "${it.name}_${"%.4f".format(Locale.US, it.lat)}" }.sortedBy { it.distanceM }.take(15)
                        cache[key] = System.currentTimeMillis() to result
                        result
                    }
                    429, 504 -> { lastError = "خدمة المعالم مشغولة، حاول بعد قليل"; emptyList() }
                    else -> { lastError = "تعذر جلب المعالم (رمز $code)"; emptyList() }
                }
            } catch (e: java.net.UnknownHostException) { lastError = "لا يوجد اتصال بالإنترنت"; emptyList() }
            catch (e: java.net.SocketTimeoutException) { lastError = "انتهت مهلة جلب المعالم"; emptyList() }
            catch (e: kotlinx.coroutines.CancellationException) { throw e }
            catch (e: Exception) { lastError = "تعذر جلب المعالم"; emptyList() }
            finally { c?.disconnect() }
        }
    }
}
```
> بيانات OSM في بعض المناطق ناقصة؛ لذلك الشاشة تسمح بالبحث بالاسم **أو بإضافة معلم يدوياً بالنقر على الخريطة** (الحل الأساسي حين تضعف التغطية).

## 6) ملف جديد: `LandmarkAddressScreen.kt`
معالج 3 خطوات: **(1) المعلم** (بحث/معالم قريبة/نقر على الخريطة) ← **(2) النقطة** (نقر على الخريطة، الإزاحة تظهر مباشرة) ← **(3) التأكيد** (وصف نصي إلزامي + «هل هذا موقع منزلك؟»).
```kotlin
package com.example.ui.screens.map

import androidx.activity.compose.BackHandler
import androidx.compose.foundation.background
import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Close
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.platform.LocalContext
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.text.style.TextOverflow
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import com.example.utils.*
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.delay
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

@Composable
fun LandmarkAddressScreen(
    centerLat: Double,
    centerLng: Double,
    hasRealLocation: Boolean,
    selectedCity: String = "الكل",
    onSaved: (LandmarkAddress) -> Unit,
    onClose: () -> Unit,
    modifier: Modifier = Modifier
) {
    val context = LocalContext.current
    val scope = rememberCoroutineScope()
    val store = remember { LandmarkAddressStore(context.applicationContext) }
    val snackbar = remember { SnackbarHostState() }

    var step by remember { mutableIntStateOf(0) }                  // 0 معلم، 1 نقطة، 2 تأكيد
    var landmarkName by remember { mutableStateOf("") }
    var landmark by remember { mutableStateOf<Pair<Double, Double>?>(null) }
    var point by remember { mutableStateOf<Pair<Double, Double>?>(null) }
    var description by remember { mutableStateOf("") }
    var label by remember { mutableStateOf("منزلي") }
    var confirmed by remember { mutableStateOf(false) }
    var query by remember { mutableStateOf("") }
    var results by remember { mutableStateOf<List<RealValhallaNavigator.SearchAddressResult>>(emptyList()) }
    var nearby by remember { mutableStateOf<List<LandmarkCandidate>>(emptyList()) }
    var busy by remember { mutableStateOf(false) }
    var message by remember { mutableStateOf<String?>(null) }
    var tapForLandmark by remember { mutableStateOf<Pair<Double, Double>?>(null) }
    var focus by remember { mutableStateOf<Triple<String, Double, Double>?>(null) }
    var manualName by remember { mutableStateOf("") }

    BackHandler { if (step > 0) { step -= 1; confirmed = false } else onClose() }

    fun chooseLandmark(name: String, lat: Double, lng: Double) {
        landmarkName = name; landmark = lat to lng; point = null
        focus = Triple(name, lat, lng); results = emptyList(); nearby = emptyList(); message = null; query = ""
        step = 1
    }

    // بحث بالاسم (Nominatim الموجود) مع debounce
    LaunchedEffect(query) {
        val q = query.trim()
        if (step != 0 || q.length < 3) { results = emptyList(); return@LaunchedEffect }
        delay(600)
        busy = true
        results = RealValhallaNavigator.searchAddressAndPlaces(
            q, emptyList(), emptyList(),
            if (hasRealLocation) centerLat else 0.0, if (hasRealLocation) centerLng else 0.0
        )
        message = if (results.isEmpty()) (RealValhallaNavigator.lastSearchError ?: "لا توجد نتائج") else null
        busy = false
    }

    val onPicked: (Double, Double) -> Unit = { lat, lng ->
        when (step) {
            0 -> tapForLandmark = lat to lng            // معلم يدوي: نطلب اسمه
            1 -> point = lat to lng
        }
    }

    val draft: LandmarkAddress? = remember(landmark, point, landmarkName, description, label) {
        val l = landmark; val p = point
        if (l != null && p != null) LandmarkAddress(
            label = label.ifBlank { "منزلي" }, landmarkName = landmarkName,
            landmarkLat = l.first, landmarkLng = l.second, pointLat = p.first, pointLng = p.second,
            description = description.trim()
        ) else null
    }
    val markers = remember(landmark, point, landmarkName) {
        listOfNotNull(
            landmark?.let { Triple("المعلم: $landmarkName", it.first, it.second) },
            point?.let { Triple("موقعي", it.first, it.second) }
        )
    }

    Box(modifier.fillMaxSize().background(Color(0xFF0B0F19))) {
        RealLeafletMapView(
            userCoords = if (hasRealLocation) Pair(centerLat, centerLng) else Pair(0.0, 0.0),
            nearbyProviders = emptyList(), nearbyStores = emptyList(), nearbyProperties = emptyList(),
            dynamicOffsets = emptyMap(),
            currentMapMode = MapMode.OSM,
            selectedCity = selectedCity,
            selectedEntity = null,
            onProviderSelected = {}, onStoreSelected = {}, onPropertySelected = {}, onDeselect = {},
            waypointMarkers = markers,
            focusPoint = focus,
            pickMode = step <= 1,
            onMapPicked = onPicked,
```

## 9) ربط العنوان بالحجز (للسائق/الفني)
في الحوار الذي ينشئ الحجز (`com.example.ui.dialogs.BookingDialog` أو الدالة التي تكتب مستند الحجز):
1. أضف قائمة اختيار «عنواني المحفوظ» (من `LandmarkAddressStore.getAll()`).
2. عند الاختيار أضف إلى بيانات الحجز: `"landmarkAddress" to address.toMap()` وضمّن `address.describe()` في نص الملاحظات.
3. في شاشة الفني/السائق: `LandmarkAddress.fromMap(booking["landmarkAddress"] as? Map<String, Any?> ?: emptyMap())?.let { LandmarkAddressCard(it, onNavigate = { a -> /* state.startNavigationViaLandmark(a) */ }) }`.
> لا أرى ملف الحجز عندك؛ AI Studio يفتح الملف الفعلي ويطبّق هذه الإضافة دون تغيير الحقول القائمة.
> **قواعد Firestore:** الحقل `landmarkAddress` يقرؤه صاحب الحجز والفني المسند فقط.

## 10) الخصوصية والأمان
- العنوان يُخزَّن مشفّراً ومحلياً؛ لا يُرسل إلا عند إرفاقه بحجز (اذكر ذلك في سياسة الخصوصية).
- Overpass وNominatim يستقبلان إحداثيات المركز/نص البحث فقط (أشر لهما في سياسة الخصوصية).
- التحقق: الوصف إلزامي (≥ 3 أحرف)، والمسافة عن المعلم ≤ 1.5 كم، وتأكيد صريح «هذا هو موقع منزلي» (طبقة حماية من خطأ التحديد).

## 12) اختبار على الهاتف
1. أطفئ GPS: افتح «🏠» ← ابحث «مسجد» أو اضغط على موقع مسجد معروف وسمّه ← اضغط موقع منزلك ← اكتب وصفاً ← أكّد ← يظهر الوصف الصحيح بالاتجاه والمسافة.
2. أغلق التطبيق وافتحه: «عناويني» تعرض العنوان (مخزّن مشفّراً).
3. «اذهب» مع GPS يعمل: ملاحة بمحطتين (المعلم ثم النقطة) والنطق الصحيح.
4. حجز بعنوان محفوظ: يصل للفني نص العنوان ونقطتاه.
5. وضع الطيران: البحث والمعالم القريبة تفشل برسالة واضحة، والنقر اليدوي على الخريطة يعمل (إن كانت البلاطات مخزّنة).
