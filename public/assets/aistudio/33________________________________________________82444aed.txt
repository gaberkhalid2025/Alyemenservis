## 1) ميزات تدّعي ما لا تفعله (عالية)
### أ) «Vela 3D (مباني ثلاثية الأبعاد)»
- `MapLayersDialog` يقول «إمالة الكاميرا بزاوية 42° مع مجسمات المباني»، و`map.html` يسمّي الطبقة «Vela 3D (مباني ثلاثية الأبعاد)». الواقع: `VELA_3D` يستخدم **نفس صور الأقمار الصناعية** (`providerKey = 'satellite'`) و`setMapPerspective` فارغة. لا إمالة ولا مباني.
- في `MapControls` ثلاثة أزرار تؤدي لنفس الشيء: «نمط الأبعاد الثلاثية» و«زاوية الرؤية والإمالة» (كلاهما `VELA_3D`)، و«الرؤية البانورامية» (تختار فعلياً `HOT`).

**الإصلاح السريع الصادق:**
1. `MapLayersDialog`: احذف سطر `LayerInfo(MapMode.VELA_3D, ...)` من القائمة، وعدّل تعليق رأس الملف.
2. `MapControls`: احذف زرّي `map_vela_3d_btn` و`map_visibility_btn`. وزر `map_pano_btn` يختار `HOT`: أعد تسمية `contentDescription` إلى «خريطة الشوارع (HOT)» وغيّر أيقونته لتناسب ذلك.
3. `map.html` داخل `setLayer`: اجعل `VELA_3D` يعمل كـ`SATELLITE` بعنوانه: `title = 'أقمار صناعية'` (احذف عبارة «مباني ثلاثية الأبعاد»).
4. `MapScreenState` (الحفظ/الاستعادة): `if (mode == MapMode.VELA_3D) MapMode.SATELLITE` حتى لا تعود حالة قديمة.
5. اترك قيمة `VELA_3D` في الـ enum للتوافق.

**لو تريد 3D حقيقياً** (مباني بارزة، إمالة): لا يمكن مع Leaflet. يتطلب MapLibre GL Native بمصدر متجهات (OpenMapTiles) وطبقة `fill-extrusion`؛ مشروع مستقل وليس إصلاحاً.

## 2) وضع «المشي/القيادة» لا يؤثر على الملاحة (عالية)
`isDrivingMode` يتغير مع رسالة «تم تفعيل وضع المشي المريح» لكنه **لا يصل** إلى `NavigationScreen` ولا إلى المحرك؛ الحساب دائماً سيارة.
### أ) MapScreenContent: مرّره
```kotlin
NavigationScreen(
    ...,
    isDrivingMode = isDrivingMode,
    ...
)
```
### ب) NavigationScreen: معامل جديد وتمريره
```kotlin
isDrivingMode: Boolean = true,
...
val result = RealValhallaNavigator.calculateRoute(context, origin, remaining, driving = isDrivingMode)
```
وأضف `isDrivingMode` لمفاتيح effect حساب المسار.
### ج) RealValhallaNavigator
```kotlin
suspend fun calculateRoute(
    context: Context, origin: NavWaypoint, waypoints: List<NavWaypoint>, driving: Boolean = true
): NavRouteResult = withContext(Dispatchers.IO) { ... computeRoute(context, origin, waypoints, driving) ... }

private suspend fun computeRoute(context: Context, origin: NavWaypoint, waypoints: List<NavWaypoint>, driving: Boolean): NavRouteResult {
    if (isReady(context)) {
        val nativeResult = nativeMutex.withLock { tryRouteWithNativeValhalla(context, origin, waypoints, driving) }
        if (nativeResult != null && nativeResult.error == null && nativeResult.coordinates.size >= 2) return nativeResult
    }
    // OSRM العام يدعم السيارة فقط → لا نستخدمه لوضع المشي
    if (driving && isNetworkAvailable(context)) { /* كما هو */ }
    return calculateDirectFallbackRoute(origin, waypoints, if (driving) 10.0 else 1.4)
}
```
وفي `formatValhallaRequest(origin, waypoints, driving)`: `put("costing", if (driving) "auto" else "pedestrian")`. وفي `calculateDirectFallbackRoute` أضف معامل `speedMps: Double = 10.0` واستخدمه في المدة بدل `10.0`.
> الأوفلاين يتطلب أن تكون حزمة Valhalla مبنية بـ costing المشي (الحزمة العادية تحتويه عادةً).

## اختبار
1. قائمة الطبقات لا تحتوي «Vela 3D» ولا تظهر أزرار الإمالة.
2. بدّل المشي ثم ابدأ ملاحة: يظهر مسار مشي، وزمن أبطأ بوضوح (≈ 5 كم/س).

4. اضغط البوصلة: يظهر اتجاهك الحقيقي بالدرجات.
