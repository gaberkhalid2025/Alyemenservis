# 🇾🇪 تطبيق دليل خدمات اليمن الشامل (Yemen Services Directory)

تطبيق أندرويد متكامل وحديث مبني بأحدث تقنيات **Kotlin** و **Jetpack Compose** و **Material Design 3** مع دعم العمل دون إنترنت (Offline-First) والمزامنة السحابية الذكية الفورية.

---

## 🚀 الميزات الرئيسية

### 1. 🤖 المساعد الذكي اليمني (AI Assistant & Voice Engine)
- محرك ذكي يفهم اللهجة والمصطلحات اليمنية المتداولة (سباكة، ماطور ماء، كنداكتر، مكيف ما يبردش، بنشر، شقق للإيجار، أطباء).
- دعم الإدخال بالأوامر الصوتية (Speech-to-Text) والنطق الآلي للإجابات (Text-to-Speech).
- إرشادات صيانة ذاتية سريعة وآمنة (DIY) مع التكلفة التقديرية.
- إمكانية إنشاء طلب صيانة مباشر أو التحقق من سجل الحجوزات بضغطة زر.

### 2. 🗺️ خريطة الخدمات والرادار الجغرافي (Free Leaflet / OSM Maps)
- خريطة تفاعلية بالكامل بدون أي مفاتيح مدفوعة أو تكاليف API.
- تحديد الموقع المباشر للمستخدم وعرض المسافة الدقيقة (بالكيلومتر والأمتار).
- أيقونات مميزة لكل فئة (🛠️ فنيين، 🏪 متاجر، 🍔 مطاعم، 🏥 مراكز طبية، 🏠 عقارات).
- إمكانية فتح مسار الاتجاهات والملاحة المباشرة.

### 3. 💬 نظام المحادثات الفورية المتطور (Realtime Chat & Media)
- مؤشر الكتابة المباشر (Typing Indicator) لمعرفة وقت كتابة الطرف الآخر.
- ميزة الرد المقتبس (Quote Reply) والتفاعلات السريعة (Reactions).
- إرسال وتنزيل الصور والمستندات والرسائل الصوتية.
- البحث الذكي داخل المحادثة مع تمييز النصوص المطابقة.

### 4. 💼 لوحات تحكم متخصصة لمقدمي الخدمات (Provider Dashboards)
- **لوحة الفنيين**: إدارة الحجوزات، تغيير حالة التوفر (🟢 متاح / 🔴 مشغول)، تعديل الأسعار، وسجل الأعمال.
- **لوحة المتاجر والمطاعم**: إدارة قائمة المنتجات والأطباق، إضافة العروض والتخفيضات، ومتابعة الطلبات.
- **لوحة المراكز الطبية**: تنظيم العيادات والأطباء، بروشور الخدمات، وحجز المواعيد.
- **لوحة المكاتب العقارية**: إدارة قوائم العقارات والشقق، معارض الصور، ومتابعة طلبات المعاينة.

### 5. 🔔 مركز الإشعارات المتقدم (Smart Notification Center)
- تصنيف الإشعارات إلى (الكل 📢، غير مقروءة ✉️، مقروءة ✅).
- منع تكرار الإشعارات وحفظ الحالة محلياً وسحابياً.

### 6. ⚡ تحسينات الأداء وتوفير البيانات
- التخزين المؤقت المحلي للصور والاستعلامات.
- بنية تعتمد على استهلاك أدنى حد من باقة الإنترنت.

---

## 🛠️ البنية التقنية (Tech Stack)
- **اللغة**: Kotlin 100%
- **واجهة المستخدم**: Jetpack Compose + Material Design 3
- **إدارة الحالة والبيانات**: Kotlin Coroutines, StateFlow, Room Database, SharedPreferences
- **الصوت**: Android SpeechRecognizer & TextToSpeech API
- **الخرائط**: Leaflet JS + OpenStreetMap عبر WebView مخصص ومؤمن
- **تحميل الصور**: Coil Compose
